# ADR-0017: Node 24

- **Status:** aceita
- **Data:** 2026-11-03

## Contexto

O projeto precisa de uma versão de Node fixa, igual na máquina de quem desenvolve e na CI.

## Opções consideradas

- Node 26, o da máquina do autor.
- Node 24.

## Decisão

Node 24, pelo suporte mais amplo do ecossistema. Fixado em `.node-version` e em `engines` (`>=24.11.0`).

## Consequências

- A CI usa o Node 24.

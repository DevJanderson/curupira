# ADR-0012: Documentação em Markdown dentro do painel

- **Status:** aceita
- **Data:** 2026-11-03

## Contexto

A documentação para pessoas precisa estar perto do trabalho e acessível sem internet.

## Opções consideradas

- Site Astro Starlight (como o Ranger): uma segunda peça para construir.
- Os mesmos `.md` de `docs/`, renderizados pelo painel.

## Decisão

Os mesmos `.md` de `docs/`, renderizados pelo painel, offline.

## Consequências

- Uma peça a menos para construir.
- A documentação pode virar site depois.

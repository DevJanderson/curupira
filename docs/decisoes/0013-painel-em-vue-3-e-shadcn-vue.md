# ADR-0013: Interface do painel em Vue 3 + shadcn-vue

- **Status:** aceita
- **Data:** 2026-11-03

## Contexto

O specwork já tem um painel, que pode ser reaproveitado.

## Opções consideradas

- Vue 3 + shadcn-vue, reaproveitando o painel do specwork.
- React + shadcn/ui.

## Decisão

Vue 3 + shadcn-vue, reaproveitando o painel do specwork.

## Consequências

- Pendência: confirmar a checagem de tipos do Vue com o TypeScript 7/tsgo do Vite+ quando o painel começar.

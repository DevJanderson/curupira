Pacotes de biblioteca compartilhados pelas aplicações entram aqui, um por pasta.

- `core`: a constante única do nome e o que deriva dela (ADR-0008), as regras da jornada, o arquivo de estado de
  cada funcionalidade e o nome de autor das decisões.
- `claude-code`: o adaptador do Claude Code (ADR-0021): lê a entrada do hook e a sessão do agente.
